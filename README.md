# IELTS Vocabulary Lab

An interactive **IELTS Academic Reading** practice game for learners working towards **Band 6.0**. Built by Andy Chum, an independent language tutor.

**[Play the game](https://saho-ielts-vocab-lab-2026.awakeazure4.chatgpt.site/)**

## What is included

- **Flashcards:** 500 vocabulary and phrase items, with Japanese explanations and examples.
- **Meaning Match:** Choose the closest meaning and learn common IELTS paraphrases.
- **Sentence Detective:** 100 challenging sentence-comprehension tasks, with Japanese explanations of long and complex sentences.
- **Reading Quest:** 76 IELTS-style questions across 14 passages, covering 17 labelled task formats (including True/False/Not Given, Yes/No/Not Given, matching, single and multiple selection, short answers, and completion), with Japanese and evidence-based feedback. Question and answer order varies between sessions.

The activities were designed to strengthen vocabulary, phrase recognition, sentence analysis and comprehension. The material is original practice content, **not an official IELTS test** or an endorsement by IELTS.

## Run locally

Download `index.html`, `app.js` and `data.js` into the same directory and open `index.html` in a browser. No installation or server is required. Progress is stored locally in your browser; it is not transmitted to the teacher.

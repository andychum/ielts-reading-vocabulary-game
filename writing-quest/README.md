# IELTS Writing Quest — Prepared by Andy Chum

**An interactive IELTS Academic Writing revision game with 100 questions and five practice modes.**

**[🎮 Play IELTS Writing Quest](https://andychum.github.io/ielts-reading-vocabulary-game/writing-quest/)**

This is a standalone learning game for students working towards stronger IELTS Writing performance, including learners aiming for **Band 7.5**. Practise recognising grammar mistakes, improving awkward sentences, describing chart data accurately and developing better arguments.

## Five game modes

| Mode | Questions | Focus |
| --- | ---: | --- |
| Grammar Detective | 25 | Subject–verb agreement, tense, passives, sentence structure and common errors |
| Sentence Surgery | 20 | Rewrite awkward sentences in natural academic English |
| Task 1 Data Detective | 20 | Describe trends and comparisons without unsupported conclusions |
| Task 2 Essay Builder | 20 | Develop arguments, explanations and essay structure |
| Band 7.5 Challenge | 15 | Mixed revision and exam-oriented editing |
| **Total** | **100** | |

## Features

- Immediate feedback and helpful English/Japanese explanations.
- Personal mistake notebook and review practice.
- Works as a browser-based game with no student registration.
- Browser-local progress tracking (progress does not automatically synchronise across devices).
- Suitable for independent study or use during online lessons.

## Use it in class

Start with Grammar Detective, practise Sentence Surgery, then attempt the IELTS Task 1 and Task 2 modes. Use the mistake notebook to revise the areas that need the most attention.

**This is independent IELTS practice content, not an official IELTS test, scoring service or endorsement.** Band 7.5 is a learning goal, not a promised result.
